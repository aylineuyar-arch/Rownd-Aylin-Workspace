# Draft Console

A static, self-contained UI mockup for a proposal-drafting tool (New Draft, Historic Submissions, Proposal Templates, New RFIs, and an Architecture diagram tab). No build step, no backend — it's a single `index.html` styled with Tailwind's CDN build.

## Run it locally

Just open `index.html` in a browser — double-click it, or:

```bash
open index.html
```

It needs internet access once, to load Tailwind and the Google Fonts it uses from their CDNs. No local server, no install, no build step.
